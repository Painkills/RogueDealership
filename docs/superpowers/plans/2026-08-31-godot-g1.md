# Godot G1 — One Shift, Playable On Screen

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the view layer on top of G0's pure `Shift` model so a player can run one full shift with a mouse — floor, hover-to-see-actions, place/build/offer/close — and end at a report screen. **No shop, no save, no new mechanics.** G1 succeeds when this is more legible than the m2 CLI it replaces.

**Architecture:** One `Shift` scene owns a `Shift` model instance and renders three panels from it every frame it changes: the floor (three `FloorCard`s), the current customer (`CustomerPanel`), and the hand (`HandCard`s). Every player action is a button press that calls exactly one `Shift` method and re-renders from the returned `Result` plus the model's own state — the view never mutates model state directly, and it never duplicates a decision the model already makes. Placeholder art only: coloured `ColorRect`/`Panel` in the exact slot sizes from `GODOT_SPEC.md` §7, so real art drops in later without moving an anchor.

**Tech Stack:** Godot 4.7 (GDScript), zero plugins. Builds on `game/scripts/model/**` from G0 — read [`game/README.md`](../../../game/README.md) for that layer's shape before starting.

**Spec:** [`GODOT_SPEC.md`](../../../GODOT_SPEC.md) §6 (screen layout, information model) and §7 (art style guide) are what this plan implements. The rules are m2's, specified in [`m2/README.md`](../../../m2/README.md) — this plan changes no rule, only how it is shown and driven.

## Global Constraints

- **Godot 4.7, GDScript, no plugins, no C#.**
- **The view never reaches into model internals it doesn't own.** It calls `Shift` methods and reads `Shift`/`Customer`/`Offer` public fields; it never edits `patience`, `line`, `margin`, etc. directly. A rule enforced by review, not a test — G0's `test_architecture.gd` already guards the reverse direction (model never imports view).
- **Information model (`GODOT_SPEC.md` §6):** patience and unsigned total are **always visible for all three chairs**. Negotiation detail — the appeal bar, their Line, ranks learned — shows **only for the customer you are with**. `WHAT THEY DO` (their archetype's actions) appears **on hover** over any floor card, live or not.
- **Base viewport 960×540**, integer scale, no texture filtering — already set in `game/project.godot` from G0.
- **Placeholder slot sizes** (`GODOT_SPEC.md` §7): customer portrait 64×64, floor card 160×112, hand card 96×132, icons 16×16.
- **Palette, 16 colours addressed by role**, not by hex value in code: `bg`, `panel`, `panel_hi`, `text`, `text_dim`, `appeal` (blue), `margin` (gold), `patience_ok` (green), `patience_warn` (yellow), `patience_bad` (red), `action` (magenta), `alert` (red), `accent`, plus three neutrals. One class owns the mapping; no scene hardcodes a colour.
- **`Palette` and `Format` are plain `class_name` classes with `static func`s, not autoloads.** `godot --headless --script` — the invocation this project's whole test suite uses — never instantiates project autoloads at all (confirmed by direct experiment during Task 1: neither compile-time symbol resolution nor a runtime `/root` lookup finds them). Since both classes are pure and stateless, a `class_name` with static methods is both the fix and the architecturally correct choice — it matches every other shared class in this codebase (`Effect`, `Trigger`, the data-pool classes), none of which use autoloads. Call syntax is unaffected: `Palette.color(...)` and `Format.money(...)` are called exactly the same way from every other task's code as if they had been autoloads.
- **`ok == false` on a `Result` means nothing was spent.** The view must never grey out or disable a button speculatively — it always lets the player try, and shows the refusal message on failure. This preserves G0's "a misclick is harmless" guarantee at the UI layer.
- **Input is mouse-first with keyboard mirrors**: `1`–`4` for hand cards, `O` offer, `C` close, `D` drop, `A`/`B`/`C` chairs, `X`+digit dig (`GODOT_SPEC.md` §6). Keyboard mirrors are **Task 9**, added last, once the mouse flow is proven.
- Money renders as `$1,600` (comma-grouped, no decimals). Appeal/Line/patience render as plain integers.

## The model API this plan builds on (from G0, read-only reference)

Copied here so tasks don't have to re-derive it from `shift.gd`. If any of this looks wrong when you start a task, **stop and re-read `game/scripts/model/shift.gd` — this table is a summary, not the source of truth.**

**Construction:**
```gdscript
var cfg: ShiftConfig = load("res://data/shift_config.tres")
var interests: InterestPool = load("res://data/interests/interest_pool.tres")
var cards: CardPool = load("res://data/card_pool.tres")
var archetypes: ArchetypePool = load("res://data/archetype_pool.tres")
var shift := Shift.new(cfg, interests, cards, archetypes, randi(), [])
# floor_ids array can force specific archetypes for testing, e.g. [&"hawk"]
```

**Commands** (all return `Result` with `.ok: bool`, `.msg: String`, `.kind: String`, `.data: Dictionary`; `ok == false` spends nothing):

| Method | When legal | Notes |
|---|---|---|
| `approach(chair: int)` | always, if not already there | free if `chairs[chair] == last_customer` |
| `leave()` | when `at != null` | always free |
| `play_card(index: int)` | `at != null` | routes to `place()` if product, `_support()` if not |
| `place(index: int)` | `at != null`, no live offer, don't already own it | `data.band: String` in ALMOST/WARM/COOL/COLD |
| `offer()` | `at != null`, `chairs[at].offer != null` | `kind` is `"sale"` or `"miss"`; `data.short`, `data.rank`, and on sale `data.margin`, `data.bonus` |
| `drop_offer()` | live offer exists | free |
| `dig(index: int)` | not over | discards hand card, draws |
| `close()` | `at != null`; refused if `chairs[at].demands` set and not owned | `data.margin: int` banked |

**Read-only state to render:**
- `shift.tick`, `shift.tick_budget`, `shift.margin_banked`, `shift.quota`
- `shift.chairs: Array` — `null` or a `Customer`, indexed 0..2 (`Shift.CHAIR_KEYS[i]` for the letter)
- `shift.walk_up: Array[int]` — ticks until a chair refills, when `chairs[i] == null`
- `shift.at` — chair index you're standing at, or `null`
- `shift.hand: Array[CardInstance]`
- `shift.events: Array[String]`, `shift.action_log: Array[Dictionary]` — **append-only**; the view tracks how many of each it has already drawn and only renders the new tail (this is how m2's CLI avoided re-printing history, and G0 preserved the same shape)
- `shift.is_over() -> bool`, `shift.margin_at_risk() -> int`, `shift.report() -> Dictionary`

**`Customer` fields to render:** `key`, `display_name`, `archetype: CustomerArchetype`, `line`, `known_line: bool`, `patience`, `max_patience`, `offer` (an `Offer` or `null`), `unsigned: Array[Dictionary]` (each has `"product"`, `"margin"`, `"bonus"`), `known_ranks: Dictionary`, `known_top_category`, `demands`, `state: String`. Methods: `unsigned_margin() -> int`, `leaving_soon() -> bool`, `owns_category(id) -> bool`.

**`Offer` fields:** `product: ProductCardDef`, `appeal: int`, `margin: int`, `revealed: bool`, `applied: Array[String]`.

**`CardInstance` fields/methods:** `card: CardDef`, `is_product() -> bool`, `margin() -> int`. `card` is either a `ProductCardDef` (`interest: Interest`, `margin: int`) or `SupportCardDef` (`needs_offer: bool`, `effects: Array[Effect]`) — both share `CardDef`'s `id`, `display_name`, `text`, `ticks`.

**`CustomerArchetype.actions: Array[CustomerAction]`**, each with `display_name`, `tell` (shown before it ever fires — this is the WHAT THEY DO panel's content).

**`Effect.describe() -> String`** — every effect can describe itself; this is how hand cards show their mechanical text without the view knowing what a `ChangeAppeal` is.

## Building scenes without the editor GUI

Tasks 2–6 each describe a `.tscn` scene as a node tree. **None of this plan's execution happens
in an interactive Godot editor** — build every scene with a throwaway builder script run via
`--script`, the same pattern G0 used for `.tres` data (`game/tools/seed_interests.gd`,
`seed_cards.gd`): construct the nodes in GDScript, set `owner` on every non-root node, `pack()`
the tree, `ResourceSaver.save()` it. This is more reliable for a non-interactive implementer than
hand-typing raw `.tscn` text, and it produces a normal, fully editor-editable scene file — nothing
about the result is different from building it by hand in the GUI.

**The pattern**, using Task 2's `HandCard` as the worked example:

```gdscript
extends SceneTree
## Bootstrap for hand_card.tscn. Run once via --script; the .tscn it writes
## is the source of truth afterward and stays editor-editable.

func _init() -> void:
	var root := PanelContainer.new()
	root.name = "HandCard"
	root.custom_minimum_size = Vector2(96, 132)
	root.set_script(load("res://scripts/view/hand_card.gd"))

	var vbox := VBoxContainer.new()
	vbox.name = "VBoxContainer"
	root.add_child(vbox)
	vbox.owner = root                     # REQUIRED on every non-root node

	var name_label := Label.new()
	name_label.name = "NameLabel"
	name_label.autowrap_mode = TextServer.AUTOWRAP_WORD
	name_label.unique_name_in_owner = true       # this is what makes %NameLabel resolve
	vbox.add_child(name_label)
	name_label.owner = root

	# ... one Label per row the task's scene description lists, same pattern ...

	var clicker := Button.new()
	clicker.name = "Clicker"
	clicker.flat = true
	clicker.unique_name_in_owner = true
	clicker.set_anchors_preset(Control.PRESET_FULL_RECT)
	root.add_child(clicker)               # added AFTER vbox so it renders on top and catches clicks
	clicker.owner = root

	var packed := PackedScene.new()
	packed.pack(root)
	DirAccess.make_dir_recursive_absolute("res://scenes")
	ResourceSaver.save(packed, "res://scenes/hand_card.tscn")
	print("saved hand_card.tscn")
	quit(0)
```

**Two rules that are easy to get wrong and silently produce a broken scene:**
- **Every non-root node needs `.owner = root` set, in the same call that adds it**, or `pack()`
  silently drops it from the saved scene (it exists in memory but never gets serialized).
- **A node needs `unique_name_in_owner = true` for every `%Name` the task's script uses.** This is
  the non-interactive equivalent of "right-click → Access as Unique Name" in the editor — same
  effect, no editor required.

Each scene task below still describes the node tree textually (that description is the
requirement); write your own builder script following the pattern above to match it, save it
under `game/tools/build_<scene>.gd` (kept in the repo afterward, same as G0's seed scripts, so the
scene's construction stays auditable and reproducible), run it once via `--script`, then verify
with `--headless --path game --import` and the test suite as usual.

- [ ] **Step 3: Write the palette**

Create `game/scripts/view/palette.gd`:

```gdscript
class_name Palette extends RefCounted
## Every color in the game is looked up by ROLE, never written as a literal
## hex in a scene script - so the whole palette can be repainted by editing
## this one file. Static methods, not an autoload: godot --headless --script
## (this project's whole test invocation) never instantiates autoloads, and
## since this class is pure and stateless it needs no instance anyway.

const ROLES := {
	&"bg": "1a1a2e",
	&"panel": "22223b",
	&"panel_hi": "2e2e4a",
	&"text": "f2f2f2",
	&"text_dim": "9a9ab0",
	&"appeal": "5da8f2",
	&"margin": "e8c15a",
	&"patience_ok": "6fcf6f",
	&"patience_warn": "e8c15a",
	&"patience_bad": "e05a5a",
	&"action": "c86fe0",
	&"alert": "e05a5a",
	&"accent": "f2925a",
	&"neutral_1": "0f0f1a",
	&"neutral_2": "3a3a5a",
	&"neutral_3": "555577",
}

static func color(role: StringName) -> Color:
	if not ROLES.has(role):
		push_error("Palette: unknown role %s" % role)
		return Color.MAGENTA
	return Color(ROLES[role])
```

Create `game/scripts/view/format.gd`:

```gdscript
class_name Format extends RefCounted
## Pure display formatting - no model knowledge, no state. Static methods,
## not an autoload, for the same reason as Palette (see palette.gd).

static func money(n: int) -> String:
	var sign := "-" if n < 0 else ""
	return "%s$%s" % [sign, _grouped(abs(n))]

static func patience_color(cur: int, max_val: int) -> Color:
	var top := max(1, max_val)
	var frac := float(cur) / float(top)
	if frac > 0.5:
		return Palette.color(&"patience_ok")
	if frac > 0.25:
		return Palette.color(&"patience_warn")
	return Palette.color(&"patience_bad")

static func _grouped(n: int) -> String:
	var s := str(n)
	var out := ""
	var count := 0
	for i in range(s.length() - 1, -1, -1):
		out = s[i] + out
		count += 1
		if count % 3 == 0 and i != 0:
			out = "," + out
	return out
```

- [ ] **Step 1: Write the script**

Create `game/scripts/view/hand_card.gd` **first** — the scene-builder script in Step 2 needs to
`load()` a real, compiling file, so the script has to exist before the scene that attaches it.

```gdscript
extends PanelContainer
## One card in hand. Purely a renderer: it knows how to show a CardInstance
## and how to say "I was clicked". It never calls a Shift method itself.

signal pressed

var index: int = -1
var instance: CardInstance

@onready var _name: Label = %NameLabel
@onready var _cost: Label = %CostLabel
@onready var _kind: Label = %KindLabel
@onready var _effect: Label = %EffectLabel
@onready var _clicker: Button = %Clicker

func _ready() -> void:
	_clicker.pressed.connect(func(): pressed.emit())

func setup(inst: CardInstance) -> void:
	instance = inst
	var def := inst.card
	_name.text = def.display_name
	_cost.text = "%dt" % def.ticks
	if inst.is_product():
		var p := def as ProductCardDef
		_kind.text = "PRODUCT  $%s" % Format.money(inst.margin())
		_kind.modulate = Palette.color(&"margin")
		_effect.text = p.interest.category.display_name + " . " + p.interest.display_name
	else:
		var s := def as SupportCardDef
		_kind.text = ""
		var effects := s.upgraded_effects if inst.upgraded and not s.upgraded_effects.is_empty() else s.effects
		var parts: Array[String] = []
		for e in effects:
			parts.append(e.describe())
		_effect.text = ", ".join(parts)
```

### Task 3: FloorCard — one chair, live patience/unsigned, hover panel

**Files:**
- Create: `game/scenes/floor_card.tscn`
- Create: `game/scripts/view/floor_card.gd`

**Interfaces:**
- Consumes: `Customer` or `null` (empty chair), `int` (walk-up ticks remaining, when empty) (G0).
- Produces: `FloorCard` scene, script exposing `func setup(customer, walk_up_remaining: int, chair_index: int) -> void`, `signal pressed(chair_index: int)`.

Per Global Constraints: patience and unsigned total are **always shown**; the `WHAT THEY DO` panel appears **on hover** via `mouse_entered`/`mouse_exited`, built from `archetype.actions[].tell`, and it must render for archetypes with an empty `actions` array too (say so, don't just show nothing — G0's design rule requires every archetype to be legible even when it does nothing).

The node tree (built via the scene-builder pattern in **Building scenes without the editor GUI**,
same as Task 2 — script first, then the builder script that attaches and saves it):
- Root: `PanelContainer` named `FloorCard`, custom minimum size `160, 112`.
- Child `VBoxContainer`:
  - `Label` `NameLabel`
  - `Label` `ArchetypeLabel` (dim text)
  - `ProgressBar` `PatienceBar` (min 0, `show_percentage = false` — shows `cur/max` via a separate label, not the bar's own percentage text)
  - `Label` `PatienceLabel` — "9/16"
  - `Label` `UnsignedLabel` — "$1,700 unsigned" or blank
  - `Label` `AlertLabel` — "! 3 LEFT" in `alert` color, visible only when `leaving_soon()`
- A `Button` `Clicker` stretched over the whole card (a direct child of the root, sibling of the
  `VBoxContainer`, added after it so it renders on top), flat, for chair selection.
- A `PanelContainer` `HoverPanel`, also a direct child of the root (added after `Clicker`, so it
  renders on top of everything when shown), initially `visible = false`, containing a
  `VBoxContainer` with a `Label` `HoverTitle` (static text "WHAT THEY DO" — nothing in the script
  sets this at runtime, so it must be baked into the scene) and a `Label` `HoverBody` (autowrap,
  the joined `tell` strings, or "Nothing. They just sit and listen." when empty).

- [ ] **Step 1: Write the script**

Create `game/scripts/view/floor_card.gd` **first** (the builder script in Step 2 needs to `load()`
it):

```gdscript
extends PanelContainer

signal pressed(chair_index: int)

var chair_index: int = -1

@onready var _name: Label = %NameLabel
@onready var _archetype: Label = %ArchetypeLabel
@onready var _patience_bar: ProgressBar = %PatienceBar
@onready var _patience_label: Label = %PatienceLabel
```

```gdscript
extends Control
## Fixed-scale bar: fill = appeal / scale, marker = line / scale. When a band
## (not a number) is all that's known, draws a flat "?" fill with the marker
## still shown, matching m2's CLI behaviour of hiding the number, not the bar.

var _appeal: int = 0
var _line: int = 0
var _scale: int = 40
var _band: String = ""

func set_state(appeal: int, line: int, scale: int, band: String) -> void:
	_appeal = appeal
	_line = line
	_scale = max(1, scale)
	_band = band
	queue_redraw()

func _draw() -> void:
	var w := size.x
	var h := size.y
	draw_rect(Rect2(Vector2.ZERO, size), Palette.color(&"panel_hi"))
	if _band != "":
		var stripe := Color(Palette.color(&"text_dim"), 0.3)
		draw_rect(Rect2(0, 0, w, h), stripe)
	else:
		var fill_w: float = w * clamp(float(_appeal) / float(_scale), 0.0, 1.0)
		draw_rect(Rect2(0, 0, fill_w, h), Palette.color(&"appeal"))
	var mark_x: float = w * clamp(float(_line) / float(_scale), 0.0, 1.0)
	draw_line(Vector2(mark_x, 0), Vector2(mark_x, h), Palette.color(&"text"), 2.0)
```

`ReportOverlay`, by contrast, **is** a static sub-scene instance baked into `shift.tscn` at build
time, because `_ready()` connects `_report_overlay.restart_pressed` immediately — it has to exist
from the moment the scene loads, not be created later.

- Root `Control` `ShiftController`, full rect anchors.
- `ColorRect` `Background` filling the screen, color set in `_ready()` from `Palette.color(&"bg")`.
- `VBoxContainer` `Root`:
  - `HBoxContainer` `TopBar`: `Label` `TickLabel`, `Label` `BankedLabel`, `Label` `AtRiskLabel`.
  - `HBoxContainer` `FloorRow` — empty at build time.
  - `Control` `CustomerSlot` — empty of a `CustomerPanel` at build time, but **does** get one static
    child now: a `Label` `EmptySlotLabel`, static text "Stand with a customer to negotiate.",
    shown when `shift.at == null` and hidden the instant a `CustomerPanel` instance is shown (see
    the corrected `_render()` below — the original draft of this node tree mentioned this
    placeholder in prose but the reference script never actually implemented it; fixed here so the
    node tree and the script agree).
  - `HBoxContainer` `HandRow` — empty at build time.
  - `RichTextLabel` `EventLog` — scrolling, append-only, shows the new tail of `shift.events` / `shift.action_log` each render.
- A separate root-level instance of `report.tscn` (a `PackedScene.instantiate()` of the file Task 5
  built, not a fresh `PanelContainer`) named `ReportOverlay`, `visible = false`.

Nodes needing `unique_name_in_owner = true`: `Background`, `TickLabel`, `BankedLabel`,
`AtRiskLabel`, `FloorRow`, `CustomerSlot`, `EmptySlotLabel`, `HandRow`, `EventLog`,
`ReportOverlay` — 10 in total. This is the first scene where a unique name lands on a whole
sub-scene instance (`ReportOverlay`) rather than a plain built-in node — the flag works exactly

- [ ] **Step 1: Write the controller**

Create `game/scripts/view/shift_controller.gd`:

```gdscript
extends Control

const FloorCardScene := preload("res://scenes/floor_card.tscn")
const HandCardScene := preload("res://scenes/hand_card.tscn")
const CustomerPanelScene := preload("res://scenes/customer_panel.tscn")

@onready var _tick_label: Label = %TickLabel
@onready var _banked_label: Label = %BankedLabel
@onready var _at_risk_label: Label = %AtRiskLabel
@onready var _floor_row: HBoxContainer = %FloorRow
@onready var _customer_slot: Control = %CustomerSlot
@onready var _empty_slot_label: Label = %EmptySlotLabel
@onready var _hand_row: HBoxContainer = %HandRow
@onready var _event_log: RichTextLabel = %EventLog
@onready var _report_overlay = %ReportOverlay
@onready var _background: ColorRect = %Background

var _shift: Shift
var _floor_cards: Array = []
var _customer_panel
var _events_seen: int = 0
var _actions_seen: int = 0

func _ready() -> void:
	_background.color = Palette.color(&"bg")
	_start_new_shift()
	_report_overlay.restart_pressed.connect(_start_new_shift)

func _start_new_shift() -> void:
	var cfg: ShiftConfig = load("res://data/shift_config.tres")
	var interests: InterestPool = load("res://data/interests/interest_pool.tres")
	var cards: CardPool = load("res://data/card_pool.tres")
	var archetypes: ArchetypePool = load("res://data/archetype_pool.tres")
	_shift = Shift.new(cfg, interests, cards, archetypes, randi(), [])
	_events_seen = 0
	_actions_seen = 0
	_report_overlay.visible = false

	for c in _floor_cards:
		c.queue_free()
	_floor_cards.clear()
	for i in range(3):
		var fc := FloorCardScene.instantiate()
		_floor_row.add_child(fc)
		fc.pressed.connect(_on_chair_pressed)
		_floor_cards.append(fc)

	if _customer_panel:
		_customer_panel.queue_free()
	_customer_panel = CustomerPanelScene.instantiate()
	_customer_slot.add_child(_customer_panel)
	_customer_panel.offer_pressed.connect(_on_offer)
	_customer_panel.close_pressed.connect(_on_close)
	_customer_panel.drop_pressed.connect(_on_drop)

	_render()

func _on_chair_pressed(chair_index: int) -> void:
	_apply(_shift.approach(chair_index))

func _on_offer() -> void:
	_apply(_shift.offer())

func _on_close() -> void:
	_apply(_shift.close())

func _on_drop() -> void:
	_apply(_shift.drop_offer())

func _on_hand_card_pressed(index: int) -> void:
	_apply(_shift.play_card(index))

func _apply(_res: Result) -> void:
	_render()
	if _shift.is_over():
		_show_report()

func _render() -> void:
	_tick_label.text = "tick %d/%d" % [_shift.tick, _shift.tick_budget]
	_banked_label.text = "banked %s / %s" \
		% [Format.money(_shift.margin_banked), Format.money(_shift.quota)]
	var risk: int = _shift.margin_at_risk()
	_at_risk_label.text = "%s unsigned on the floor" % Format.money(risk) \
		if risk > 0 else "nothing unsigned"

	for i in range(3):
		_floor_cards[i].setup(_shift.chairs[i], _shift.walk_up[i], i)

	if _shift.at != null:
		var cust: Customer = _shift.chairs[_shift.at]
		var band := ""
		if cust.offer != null and not cust.offer.revealed:
			band = _shift.band_for(cust.line - cust.offer.appeal)
		_customer_panel.visible = true
		_empty_slot_label.visible = false
		_customer_panel.setup(cust, band)
	else:
		_customer_panel.visible = false
		_empty_slot_label.visible = true

	for child in _hand_row.get_children():
		child.queue_free()
	for i in range(_shift.hand.size()):
		var hc := HandCardScene.instantiate()
		_hand_row.add_child(hc)
		hc.setup(_shift.hand[i])
		hc.index = i
		hc.pressed.connect(_on_hand_card_pressed.bind(i))

	for line in _shift.events.slice(_events_seen):
		_event_log.append_text(line + "\n")
	_events_seen = _shift.events.size()
	for entry in _shift.action_log.slice(_actions_seen):
		var color := "red" if entry["floor_wide"] else "purple"
		_event_log.append_text("[color=%s]>> %s (%s): %s - %s[/color]\n"
			% [color, entry["customer"], entry["key"], entry["name"],
				", ".join(entry["descriptions"])])
	_actions_seen = _shift.action_log.size()

func _show_report() -> void:
	_report_overlay.visible = true
	_report_overlay.setup(_shift.report())
```

This matches Task 2's interface exactly: `HandCard.pressed` carries no arguments, and `_render()` supplies the index via `.bind(i)` when it connects each freshly-instantiated card.
