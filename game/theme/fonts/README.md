# Fonts

**Oswald-Variable.ttf** - Oswald, by Vernon Adams, Kalapi Gajjar and Cyreal
(the Oswald Project Authors, https://github.com/googlefonts/OswaldFont).
Licensed under the SIL Open Font License 1.1 (https://openfontlicense.org);
the copyright notice and the license are also carried in the font file's own
name table. Downloaded from https://github.com/google/fonts (`ofl/oswald`,
originally `Oswald[wght].ttf`, renamed so the path has no brackets).

Used for headings, buttons and the HUD's numbers - see `tools/build_theme.gd`.
Body text stays on Godot's built-in default font.
